# Rabbi Hasan Himel — Portfolio

A single-page, responsive portfolio built with plain HTML, CSS and JavaScript.

## Free deployment

### Vercel
1. Create a GitHub repository, e.g. `rabbi-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to Vercel and import the GitHub repository.
4. Framework preset: **Other**.
5. Deploy.

No build step is required.

### GitHub Pages
You can also enable GitHub Pages from the repository settings and deploy the root folder.

## Update before publishing
- Replace/add project links.
- Add your publication DOI links if desired.
- Add your CV PDF as `cv.pdf` and a "Download CV" button if you want one.
- Confirm your current availability/location and experience dates.
